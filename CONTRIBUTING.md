# Contributing

Forks and pull requests are welcome, including ones made with AI tools.

1. Fork the repository and create a branch from `main`.
2. Read [AGENTS.md](AGENTS.md) for layout and rules.
3. Make one focused change per pull request.
4. Run `dotnet build KovaaksCompanion.slnx -c Release`. It must succeed.
5. Open a pull request. Say what changed and why, in a few lines. Add a screenshot for UI changes.

Commit messages are in English, with a type prefix such as `feat:`, `fix:` or `chore:`.
